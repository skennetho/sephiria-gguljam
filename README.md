# 🍯 sephiria-gguljam (세피리아 꿀잼)

> **세피리아(Sephiria)**의 인벤토리 배치 스트레스는 날리고, 실시간 정보와 편의성으로 게임을 꿀잼으로 즐기는 인게임 오버레이 & 플러그인 도구입니다.

---

## ✨ 주요 기능

### 1. ⚡ 인벤토리 최적 배치 & 1-클릭 게임 자동 반영 (`Ctrl + D`, `Ctrl + R`)
- **정밀한 석판 시뮬레이션**: 인게임 석판 DSL(`ParseQuery`)과 동일한 규칙으로 회전/조건/증폭/곱연산(`MUL`)을 100% 일치하게 계산합니다.
- **원클릭 인게임 자동 반영**: 최적화된 배치를 계산한 뒤, 클릭 한 번으로 게임 내 인벤토리 아티팩트 위치를 자동으로 재배치합니다.
- **되돌리기 (Undo)**: 이전 배치로 언제든지 1-클릭 원상복구 가능합니다.
- **다양한 최적화 모드**: 균등 강화 모드, 특정 콤보 집중 모드, 미니 그리드 시각화 제공.

### 2. 👥 실시간 멀티플레이 팀원 빌드 HUD (`F1`)
- **실시간 Mirror 네트워크 동기화**: 플러그인을 설치한 본인 화면에서 다른 파티원(팀원)들의 현재 인벤토리 배치, 장착 무기, 활성화된 콤보를 실시간으로 확인할 수 있습니다.
- **전체 요약 뷰 (`[ 👥 전체 요약 ]`) — v0.4.0 신규**:
  - 팀원 1명당 1개의 가로형 카드로 압축하여 파티 현황을 한눈에 요약 (1행: 닉네임 + 무기 + 기적 + 활성 콤보 / 2행: 석판 & 아티팩트 아이콘 + 강화수치).
  - 2×2 다중 격자 석판 중복 렌더링 원천 방지 및 최대 2줄(84px) 슬림 스크롤 적용.
  - 상단 탭을 통해 `[ 👥 전체 요약 ]` ↔ `[ 🔍 개별 상세 ]` 즉시 토글 가능 (설정 영속화).

### 3. 📖 sephiria.wiki 인게임 빌드 브라우저 (`Ctrl + B`)
- **위키 빌드 탐색 & 즐겨찾기**: [세피리아 위키](https://www.sephiria.wiki)의 최신 추천 빌드를 게임 안에서 바로 검색하고 나만의 즐겨찾기를 관리할 수 있습니다.
- **인게임 간소화 HUD 모드 (`[ ⊟ 간소화 ]`) — v0.4.0 신규**:
  - 게임 플레이 화면 가림을 최소화하기 위해 텍스트(설명/스탯/과일꼬치)와 코스튬을 숨기고, 무기/기적을 30px 가로 미니 칩으로 압축한 370px 초슬림 HUD 모드 제공.
  - 각 아티팩트 그룹 타이틀 옆 체크박스로 원하는 장비 섹션만 원클릭 필터링 노출 가능.
- **원클릭 인게임 프리셋 생성 & 직통 저장**:
  - **프리셋 코드 자동 생성**: 프리셋 코드가 없는 빌드도 코스튬·무기·관심부적·재능·과일꼬치를 분석해 세피리아 공식 규격(`AAF_PRESET_OBFZ|v1...`)으로 자동 합성하여 클립보드에 복사합니다.
  - **인게임 슬롯 원클릭 저장**: 오버레이에서 원하는 슬롯 번호만 누르면 게임 내부 프리셋 슬롯에 빌드가 즉시 저장됩니다.
- **마우스 오버레이 상세 툴팁**:
  - **무기**: 1~3티어 파생 트리, 고유 강화 효과
  - **캐릭터(코스튬)**: 해금 조건(🔓), 긍정 스탯(▲) 및 부정 페널티(▼)
  - **아티팩트 / 기적**: 강화 단계별 수치 및 소속 콤보 태그
- **보유 현황 자동 체크**: 내가 현재 보유 중인 아티팩트는 빌드에서 녹색 체크로 자동 표시됩니다.

### 4. ⚙️ 설정 패널 & 인앱 업데이트 (`Ctrl + ,`)
- **인앱 업데이트**: 게임 안에서 최신 버전을 확인하고 바로 업데이트할 수 있습니다.
  - **패치 업데이트** (예: 0.4.0 → 0.4.1): 오버레이만 교체 — 게임은 계속 플레이하면서 즉시 적용
  - **마이너/메이저 업데이트** (예: 0.4.x → 0.5.0): 게임 종료 시 자동으로 DLL까지 교체
- **환경설정**: 언어 변경(한국어/English), 버전 정보, GitHub 링크

### 5. 🌐 다국어 지원 (한국어 / English)
- 모든 UI, 콤보 명칭, 툴팁이 한국어와 영어로 제공됩니다.
- 핫키바 또는 설정 패널에서 언어를 즉시 전환할 수 있습니다.

### 6. 🎮 마우스 투과 & 초경량 성능 (Zero FPS Drop & 즉시 종료)
- 오버레이 패널이 닫혀 있을 때는 마우스 클릭이 게임으로 100% 투과되며, 창 합성이 완전히 비활성화되어 인게임 프레임 드랍이 전혀 없습니다.
- **게임 종료 즉시 종료 (v0.4.0 신규)**: 게임 연결이 끊기면 0초 만에 오버레이 창을 숨기고 완전히 프로세스를 종료하여 단축키 선점이나 잔여 프로세스가 남지 않습니다.

## ⌨️ 단축키 안내

| 단축키 | 기능 설명 |
|---|---|
| **`Ctrl + D`** | **최적 배치 패널** (새로고침 → 계산 → 1-클릭 반영 / 되돌리기) |
| **`Ctrl + R`** | **최적 배치 즉시 계산** |
| **`Ctrl + B`** | **위키 빌드 브라우저** (인기/최신 빌드 검색 및 즐겨찾기) |
| **`F1`** | **실시간 팀원 빌드 패널** (멀티플레이 파티원 인벤토리/무기/콤보) |
| **`Ctrl + ,`** | **설정 패널** (업데이트, 언어, 버전 정보) |
| **`Ctrl + H`** | 하단 단축키 바 숨기기 / 표시 |
| **`Ctrl + Q`** | 오버레이 종료 |
| **`F5`** | 오버레이 UI 새로고침 (개발용) |

> ⚠️ 게임 그래픽 설정에서 화면 모드를 **"테두리 없는 창(Borderless)"** 또는 **"창 모드"**로 설정해야 오버레이가 정상 표시됩니다.

## 🚀 빠른 시작 (설치 & 업데이트 방법)

### 일반 사용자 (간편 설치 및 업데이트)
1. **[Releases](https://github.com/skennetho/sephiria-gguljam/releases)** 에서 최신 `sephiria-gguljam-vX.X.X.zip`을 다운로드하고 압축을 풉니다.
2. 게임을 종료한 상태에서 **`Install.bat`**을 더블클릭합니다.
   * 자동으로 스팀의 세피리아 설치 경로를 찾아 BepInEx, 플러그인, 오버레이를 한 번에 설치/업데이트합니다.
   * **업데이트 시**: 기존 사용자의 설정값, 즐겨찾기, 프리셋 등 유저 데이터를 100% 안전하게 백업 및 보존하며 최신 버전으로 업그레이드합니다.
3. 게임을 실행하면 오버레이가 함께 시작됩니다!
4. **v0.3.0부터**: 게임 안에서 `Ctrl + ,` 설정 패널을 열어 직접 업데이트를 확인하고 적용할 수 있습니다.

> **안전 삭제 및 순정 복원**: 동봉된 **`Uninstall.bat`**을 실행하면 플러그인이 깔끔하게 제거되고 게임이 순정(Vanilla) 상태로 복원됩니다. 사용자가 수동으로 일부 파일을 먼저 지웠거나 순서가 꼬여도 오류 없이 유동적으로 잔여 파일을 정리합니다.

## 🏗️ 개발자 가이드 & 빌드

### 요구 사항
- [.NET SDK 8.0+](https://dotnet.microsoft.com/)
- [Node.js 18+](https://nodejs.org/)

### 프로젝트 구조
```
sephiria-gguljam/
├── SephiriaPlugin/               # BepInEx 5.x C# 플러그인 (게임 데이터 수집 & WS 서버)
│   ├── Plugin.cs                 # 진입점 & BepInEx 설정
│   ├── DataCollector.cs          # 인벤토리/팀원/맵 수집 및 인게임 재배치 적용
│   ├── PresetHandler.cs          # 인게임 프리셋 슬롯 직통 저장
│   ├── OptimizeSnapshot.cs       # 석판 파싱(ParseQuery) 및 스냅샷 생성
│   ├── SimpleWebSocketServer.cs  # 오버레이 통신용 로컬 WebSocket (기본 포트 5827)
│   └── Models.cs                 # 데이터 직렬화 모델
│
├── overlay/                      # Electron + HTML/CSS/JS 인게임 오버레이
│   ├── main.js                   # 투명 윈도우 & 글로벌 단축키 & 인앱 업데이트 IPC
│   ├── src/
│   │   ├── i18n.js               # 다국어 엔진 (한국어/영어)
│   │   ├── gamedata.js           # 아이템 DB, 무기 트리, 코스튬 데이터
│   │   ├── tooltip.js            # 마우스 호버 리치 툴팁 렌더러
│   │   ├── updater.js            # 인앱 업데이트 엔진 (GitHub Releases)
│   │   ├── optimizer-panel.js    # 최적배치 UI & 1-클릭 반영/되돌리기
│   │   ├── builds-panel.js       # 위키 빌드 브라우저 & 검색
│   │   ├── team-panel.js         # 실시간 멀티플레이 팀원 뷰어
│   │   └── settings-panel.js    # 설정 & 업데이트 패널
│   └── optimizer.js              # 그리드 최적화 탐색 알고리즘
│
├── assets/                       # 아이콘 및 데이터 (위키 473종 오프라인 캐시 포함)
├── scripts/                      # 빌드, 로컬 배포, 설치/제거 스크립트
└── dist/                         # 릴리스 패키징 산출물
```

### 테스트 & 빌드 명령어
```powershell
# 1. 전체 테스트 (최적화 40건 + i18n + 프리셋 코덱)
node overlay/optimizer.test.js
node overlay/i18n.test.js
node overlay/preset-codec.test.js

# 2. 플러그인 빌드
dotnet build -c Release SephiriaPlugin

# 3. 배포용 ZIP 패키징
node scripts/build-release.mjs
```
