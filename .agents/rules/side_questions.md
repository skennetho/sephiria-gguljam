# Side Question Conciseness Rule (사이드 질문 간결성 규칙)

When the user asks a side question using prefixes such as `"질문: "` or `"사이드질문"`:
1. Provide an **extremely concise, direct, and focused answer** (핵심 위주로 최대한 간결하게 답변).
2. Avoid unnecessary background explanations, long step-by-step code dumps, or multi-paragraph theories unless explicitly requested.
3. Highlight key numbers or conclusions in 1-3 short bullet points.
