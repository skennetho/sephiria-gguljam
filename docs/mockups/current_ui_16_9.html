⚠️ 16:9 환경에서 발견된 문제점

  • 인게임 가방 간섭: 위키 빌드(우측)가 열려있을 때 인게임 인벤토리(Tab)를 열면 우측 절반이 가려짐.
  • 좌측 시야 과밀: 최적배치(404px)와 팀원(404px)을 동시에 켜면 화면 좌측 25%가 완전히 덮임.
  • 해상도 대응 부재: 1080p, 1440p(QHD), 4K에서 글자 크기와 여백이 고정 px라 모니터별 비율 불균형.

💡 UX 개편 권장 방향

  • 가변/독(Dock) 사이드바: 좌/우측 분산 배치가 아닌 통합 사이드 패널 또는 슬림 HUD 모드 지원.
  • 스마트 자동 축소: 인게임 인벤토리나 전투 시 패널을 미니 바(Mini-bar)로 접는 기능.
  • 반응형 rem/vw 전환: 16:9 해상도(FHD~4K)에 맞춰 모든 패널과 그리드가 자동 비례 스케일링.
